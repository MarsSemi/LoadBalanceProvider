指標參考
TTFT（首個 Token 生成時間）
模型開始回應前的延遲。衡量 Prompt 處理速度，越低越好。
pp TPS（Prompt 處理 TPS）
預填充階段每秒處理的輸入 Token 數，越高越好。
TPOT（每個 Token 的耗時）
每個 Token 生成之間的平均耗時，越低越好。
端到端延遲（End-to-End）
從提交請求到完整回應的總時間，包含預填充與生成。
tg TPS（Token 生成 TPS）
每秒生成的 Token 數，為 TPOT 的倒數，越高越好。
總吞吐量
每秒處理的 Token 總數（輸入 + 輸出），衡量整體使用率。
批次大小
同時處理的並發請求數。批次越大總吞吐量越高，但單個請求延遲會增加。
加速比
相對於單一請求基準（1x）的 Token 生成吞吐量倍數，越高越好。
